## Known observed error types

- `NLP` and `GCP` were missed when a JD contained the expanded terms.
- Qwen sometimes considered unrelated technologies (Django vs FastAPI or PostgreSQL vs Redis) supporting evidence.
- Qwen missed an explicit 3+ years Python criterion with batch size 3 even though the CV mentioned five years.
- A job title by itself must not count as demonstrated proficiency.
